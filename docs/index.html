FEATURES

把译文放在原文旁边，而不是替掉原文

所有能力都在浏览器里完成；页面结构、样式与交互保持原样。

段落双语对照

译文插入段落、列表项下方，用 closed Shadow DOM 隔离，既不污染页面样式，也不被二次翻译。

划词翻译

选中文本弹出小窗，可在工具栏或设置页随时开关；仅当检测到翻译源语言时才出现。

图片 OCR 翻译

框选屏幕区域，Tesseract.js 在本地完成文字识别，再由离线引擎翻译，截图内容不上传。

完全离线

模型缓存完成后，翻译请求零网络。打开开发者工具的 Network 面板就能亲自验证。

更多语言包

从 Bergamot 官方索引按需下载 20 个语言对，逐文件 SHA-256 校验，随时可删除。

隐私优先

无统计、无账号、不保存翻译历史。设置项与模型只存在扩展私有存储中，卸载即清空。

HOW IT WORKS

一次翻译，全在设备内

内容脚本只负责采集与注入，模型推理跑在 offscreen 文档的 Bergamot WASM 引擎里。

网页段落→ 内容脚本采集→ Service Worker 分批→ offscreen · Bergamot WASM→ 译文注入（Shadow DOM）

FAQ

常见问题

为什么有些网站不显示译文？

收集器会穿透 open Shadow DOM 并覆盖 iframe，但 closed Shadow DOM 无法枚举，这是浏览器安全边界。动态加载的内容由 MutationObserver 跟进；用 canvas 绘制的文字无法提取。

翻译会把我的网页内容传出去吗？

不会。翻译请求不经过网络，可用开发者工具的 Network 面板验证。仅首次下载模型、语言包、OCR 数据会联网，且全部带完整性校验。

支持 Firefox 吗？

当前不支持。Firefox 的 MV3 用 event page 而非 service worker，也没有 offscreen API；移植需要一份独立 manifest 与宿主适配层，已列入后续路线。

模型占多少空间？可以删除吗？

en↔zh 每方向约 45 MB，缓存在扩展私有的 IndexedDB。设置页可删除已安装的语言包，卸载扩展会清空全部本地数据。

除了英中还能翻译别的语言吗？

可以。设置页「更多语言包」列出 Bergamot 官方索引中的 20 个语言对，逐文件 SHA-256 校验；安装后即出现在翻译方向下拉里。
