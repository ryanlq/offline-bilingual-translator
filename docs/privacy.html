隐私政策

隐私政策

最后更新：2026 年 11 月 15 日 · 适用于扩展 v0.1.0

所有翻译都在你的设备上完成。 翻译引擎（Bergamot WASM）与语言模型在下载完成后完全存于本地，翻译请求不会发送到任何服务器——可通过浏览器开发者工具的 Network 面板直接验证。

扩展需要联网的唯一场景

场景 说明
首次下载语言模型 en↔zh 模型（约 45 MB/方向）来自 Mozilla 官方 CDN
下载其他语言包 来自 Bergamot 官方模型仓库，仅在主动安装时获取
首次使用 OCR 识别语言 识别数据来自 Tesseract 官方源，仅所选语言

以上下载均带 SHA-256 完整性校验，下载后即离线可用，无需重复联网。这些请求不包含任何页面内容、译文或浏览活动。

仅在本机处理的数据

为生成译文，扩展必须在本机读取两类「网站内容」：当前网页的段落文本（页面翻译 / 划词翻译），以及你主动框选的屏幕区域或右键指定的图片（OCR 翻译）。这些内容只在内存中即时处理：不写入磁盘、不上传、不与第三方共享，结果展示后即丢弃。商店政策要求「仅本地处理也需披露」，因此我们在 Chrome / Edge 表单中只申报 Website content（网站内容）一类，其余类别均不适用：代码从不读取 tab.url / tab.title、不建立浏览历史；鼠标与选区事件只用于即时触发翻译功能，不做任何日志。

我们绝不收集的数据

  • 无统计分析 / 埋点 / 遥测 / 崩溃上报
  • 无账号体系，不需要任何登录
  • 不收集个人身份、健康、财务、认证、通讯与位置信息
  • 不读取、不保存浏览历史与用户活动记录
  • 不保存翻译历史：译文只在页面内展示，关闭页面即消失
  • 设置项仅保存在浏览器本地的扩展私有存储中

数据共享与第三方

我们不出售、不共享、不向第三方传输任何用户数据。由于根本不收集个人数据，服务器端不存在需要披露、转移或删除的信息。扩展声明的远程域名只用于下载公开的模型与 OCR 数据文件。

本地数据的存放位置

  • 语言模型：IndexedDB（扩展私有存储）
  • 设置项与已装语言包信息：chrome.storage.local（扩展私有存储）

设置页可随时删除已下载的语言包；卸载扩展即删除全部本地数据。

如何自行验证

源码公开可审计：github.com/ryanlq/offline-bilingual-translator。打开开发者工具 → Network 后翻译任意页面，不会产生任何请求；仓库中的 PRIVACY.md 也有简要说明。

联系与反馈

对本政策的疑问可在 GitHub Issues 提出；我们不收集邮箱，也没有邮件列表。
